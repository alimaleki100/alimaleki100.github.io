Snapp Order Center: Event-Driven Streaming Data Platform

Directing the 5-person Data Engineering workstream for the core Order Center microservice ecosystem, processing 10M+ daily transactional events with sub-second SLAs and real-time dispatch observability.

01 / Context & Operational Scale

Handling 10M+ Daily Orders Across Ride-Hailing and Super-App Services

Snapp operates as the premier super-app in the region, orchestrating ride-hailing, food delivery, grocery fulfillment, and freight logistics. As transaction volumes expanded to millions of orders per day, the core Order Center microservice faced unprecedented demand for real-time order state propagation, fraud monitoring, and operational tracking.

Legacy batch ingestion processes struggled to keep pace with flash traffic spikes, creating database lock contention on transactional PostgreSQL clusters and delaying critical operational telemetry for dispatch operations.

02 / Technical Architecture & Team Leadership

High-Throughput Streaming Ingestion & Real-Time Search Indexes

I led a dedicated 5-person Data Engineering team within the Order Center domain, designing and executing a resilient event-driven data pipeline:

  • Change Data Capture (CDC) & Kafka Streaming: Implemented real-time transactional replication from PostgreSQL using Debezium and Apache Kafka, eliminating heavy polling loads on primary databases.
  • Distributed Elasticsearch Indexing: Built high-speed indexing pipelines allowing operational teams to search, filter, and analyze multi-million order lifecycles in real time.
  • Data Contracts & Schema Registry: Enforced strict schema validation using Avro and Schema Registry, ensuring microservice releases never broke downstream streaming consumers.
  • Observability & Dead-Letter Queues: Configured comprehensive lag monitoring, automated failover mechanisms, and dead-letter queues to guarantee zero message loss during peak load surges.

Core Pipeline Architecture

PostgreSQL → Debezium Non-blocking CDC streaming capture of row-level order state mutations.
Apache Kafka Cluster High-throughput partitioned event topics handling 10,000+ msgs/sec.
Elasticsearch & Kibana Sub-second operational query engine for fleet dispatchers and customer support.
